# SkyStore — Интернет-витрина на Django

Веб-приложение для публикации каталога товаров с разделением прав доступа (модерация/владение) и оптимизацией производительности с помощью Redis.

## 🛠 Технологический стек
* **Backend:** Django 6.x (Python 3.14)
* **Database:** PostgreSQL
* **Caching & Broker:** Redis + `django-redis`
* **Dependency Management:** Poetry / Pip (requirements.txt)
* **Styling:** Bootstrap 5

## 🚀 Функционал проекта
1. **CRUD Продуктов и Категорий:** Полный цикл управления данными через Class-Based Views (CBV).
2. **Кастомная авторизация:** Регистрация и аутентификация пользователей по паре `Email` и `Пароль`.
3. **Безопасность и Валидация:**
   * Защита от спама (блокировка запрещенных слов в названиях/описаниях товаров).
   * Проверка корректности цен (запрет отрицательных значений).
4. **Разграничение прав (RBAC):**
   * Гости могут только просматривать общую страницу каталога.
   * Авторизованные пользователи могут управлять только *своими* продуктами (`owner`).
   * Группа **«Модератор продуктов»** имеет право удалять любые товары и снимать их с публикации.
5. **Оптимизация (Кеширование):**
   * Низкоуровневое кеширование списков товаров в Redis.
   * Полное кеширование страниц деталей продукта (`cache_page`).
   * Архитектура сервисных функций для фильтрации по категориям (`services.py`)
